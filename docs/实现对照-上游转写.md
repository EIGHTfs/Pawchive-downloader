# 实现对照（上游 Python 实现 → 本 CLI）

| 上游原实现 | 本 CLI |
|-----------------|--------|
| `parse_webpage_url` | `parseWebpageUrl`（service / user / post 解析） |
| `PawchiveClient.list_creator_links` | `buildPlan` 内 links 拉取（同作者跨渠道） |
| `get_file_url`（files_netloc + /data 前缀） | `getFileUrl` |

| `Downloader`（Range 断点续传 + tenacity 重试 + TPS） | `downloadFile` / `streamOnce`（curl + UA + HTTP/1.1） |
| `duplicate_file_check` | `fileExists` 查重跳过 |
| bucket 存储硬链接复用 | `buildHashIndex` + `linkOrCopy`（hash 索引来自 pawchive-index.html） |
