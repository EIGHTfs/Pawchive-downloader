# 前端优化修复记录（KToolBox WebUI 前端——2026-09-28/29）

> 范围：KToolBox WebUI 前端（webui/src + 构建产物 static bundle）——五波排查修复「URL 变视图不更新 / 切页空白 / 内容未完全渲染 / 冷启动卡」四类问题。
> 现状：修复已部署原版 8791 与我们兼容层 8790（同 bundle `index-Be5kOo42.js`）；源码修复已推送到上游 PR #396（commit `2aea0bdc`）。

## 一、问题现象（四类，逐次定位）

| # | 现象 | 触发 | 用户反馈 |
|---|---|---|---|
| 1 | 侧边栏切换后**网址变了但视图不更新**（一直显示旧路由内容） | 点击侧边栏导航（/naming→/mcp→/setting） | 刷新恢复正常 |
| 2 | 侧边栏切换/创建任务后**页面空白**（白屏无内容） | 切换路由/添加任务 | 刷新恢复正常 |
| 3 | 切页后**内容未完全渲染**（部分组件/数据未出现） | 切换 MCP/全局配置等页 | 部分缓解但仍在 |
| 4 | **刚启动时卡**（冷启动首屏慢） | 首次打开（冷启动） | 之后操作正常（热缓存） |

## 二、根因（三个独立问题）

### 根因 1：react-router v7 BrowserRouter 默认 useTransitions=true（问题 1/2 主因）
- `react-router` v7.18.4 的 `<BrowserRouter>` **默认 `useTransitions=true`**：location 更新经 `React.startTransition`（低优先级）调度；特定时机该 transition 更新被 React **丢弃/不提交** → `window.history`（地址栏）已更新但 React 树未重渲染 → 视图停留旧路由。刷新=整树重载恢复正常。
- 无渲染异常（无 console/window.onerror 错误）——故 ErrorBoundary 兜不住该场景。
- 验证：A/B 实验（恢复上游原始 src 同样卡——与任何额外改动无关，上游通病；实验 C 加 `useTransitions={false}` 后七路由全部正常）。

### 根因 2：整页 PageLoading gating 依赖非主必需查询（问题 3）
- 多个页面「整页 loading 门禁」依赖**非主必需查询**（creators/conversions/dotenv/layoutVersions 等）——任一查询首次冷请求慢/挂起 → **整页内容区空白**；刷新后二次查询命中缓存快 → 「刷新恢复」。
- 实测复现：延迟注入 /api/v1/blockers 8s 后切 /blockers → 整页空白 6s+（PageLoading 等待），查询返回才渲染。
- 涉及页面：TasksPage/BlockersPage/AutomaticSyncPage/DashboardPage/NamingPage/MCPPage/ConfigurationPage。

### 根因 3：首屏 bundle 全量加载+解析（问题 4）
- 单入口 js 734KB **含全部页面组件** + 总计 2.8MB（js 2348KB + css 475KB）全量传输+解析——冷启动卡的主因是**浏览器 JS 解析量**（端点毫秒级、服务内存正常——卡在前端解析）。

## 三、修复（五波，逐项）

### 波 1：ErrorBoundary 兜底（渲染异常可见化）
- 新建 `webui/src/components/ErrorBoundary.tsx`（130 行）：类组件——渲染错误显示可见兜底 UI（错误 message + 刷新/重试按钮，纯内联样式）；自动上报 `POST /api/v1/client-error`（sendBeacon/keepalive——与兼容层 ① 层同通道 → .client-errors.jsonl）。
- `webui/src/main.tsx`：根级 `<ErrorBoundary label="root">` 包 `<BrowserRouter>`；createRoot 追加 React 19 `onUncaughtError`（root 级未捕获错误记录+上报）。
- `webui/src/components/AppShell.tsx`：`<Outlet />` 外包 `<ErrorBoundary key={location.pathname} label="route">`——路由切换渲染异常→兜底 UI 而非白屏。
- 产物验证：vendor chunks（react-runtime/heroui/date 等 8 个）哈希全不变=最小改动。

### 波 2：useTransitions={false}（根因 1 修复——URL 变视图不更新）
- `webui/src/main.tsx`：`<BrowserRouter useTransitions={false}>`（官方开关——location 更新恢复同步紧急 setState——transition 不再丢弃）。
- A/B/C 实验确认：原始 src 同样卡（根因与波 1 无关）；`useTransitions={false}` 后七路由全跟随。

### 波 3：七页整页 gating 最小化（根因 2 修复——慢查询不阻塞整页）
| 文件 | 原 gating | 改后 |
|---|---|---|
| TasksPage.tsx | tasks‖creators‖project | 仅 tasks |
| BlockersPage.tsx | blockers‖creators | 仅 blockers |
| AutomaticSyncPage.tsx | plans‖creators‖runs | plans‖runs |
| DashboardPage.tsx | project‖tasks‖creators | project‖tasks |
| NamingPage.tsx | naming‖conversions‖legacyContext‖layoutVersions‖… | 仅 naming（主表单） |
| MCPPage.tsx | status‖tokens‖tools | 仅 status |
| ConfigurationPage.tsx | schema‖dotenv‖production‖project | 仅 schema |

- 依赖处全部 `?? []` / `?.` 兜底（防 undefined.length 类崩——与 8790 /tasks 详情同类坑）。
- 修复确认（延迟注入）：conversions 挂起 8s 切 /naming → 主表单 0.5s 渲染完整（修复前整页空白 8s）。

### 波 4：ErrorBoundary key remount → resetKey（切页免整树重挂）
- AppShell.tsx + ErrorBoundary.tsx：切页由「整树重挂（key=pathname）」改为「实例复用 + resetKey 变化自动清兜底态」——消除切页整树重挂开销，兜底/自动恢复功能不变。

### 波 5：路由级懒加载（根因 3 修复——首屏冷启动）
- `webui/src/App.tsx`：10 个非首屏页面（Tasks/AutoSync/Creators/Posts/Blockers/Config/Naming/MCP/System/About）改 `lazy(() => import(...).then(named))`；Routes 外包 Suspense（spinner fallback）；首屏相关（Login/Dashboard）保持静态。
- 拆包效果：**入口 734KB → 93KB（-87%）**；NamingPage 458KB（CodeMirror）/TasksPage 43KB/MCP 18KB/Config 15KB 等全部独立 chunk 按需加载。
